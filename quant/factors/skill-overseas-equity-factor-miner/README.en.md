# 🧩 Overseas Equity Factor Miner

[简体中文](README.md) | **English**

> One-line positioning: run a **cross-sectional alpha-factor discovery loop** on **Hong Kong or US** equities — generate candidate factors, compute them point-in-time, and screen and rank top-K by **IC, decay, and turnover** — rather than applying a fixed factor set.

## 📖 What This Is

A **factor mining / discovery loop** skill, not a packaged fixed-factor library. It drives an agent through a full cross-sectional factor-research workflow:

- **Inputs**: market (HK **or** US, never mixed), universe (explicit list or index constituents), factor families (momentum/reversal, value/quality, liquidity/turnover), forward-return horizons (e.g. 5/10/20 trading days), and a compute budget.
- **Processing**: set rebalance dates via `get_trade_cal(exchange=HK|US)` → generate candidate factors → assemble **point-in-time** price and fundamental panels → compute cross-sections (fundamental factors **normalized within the peer group via `*_median`**, long tables deduped to one report caliber) → validate each candidate by **rank IC (Spearman) / IC decay / turnover** → rank → output top-K.
- **Outputs**: a factor-mining report (Markdown) with candidate formulas, an IC/decay/turnover table, a ranking, caliber & risk notes, and a data-source table.

It **does not call data APIs directly** — every Pandadata call is delegated to the sibling **`skill-pandadata-api`** skill, which owns the exact method signatures and field names.

### How it differs from sibling repos

| Need | Use |
|---|---|
| **Discover / mine / screen** HK/US factors (this repo) | `skill-overseas-equity-factor-miner` |
| **Apply** an already-standardized HK/US fundamental factor set | `skill-hk-us-fundamental-factor` |
| A-share OHLCV factor libraries | the `quant-factor-*` collections |

## 🚀 Quick Start

```bash
cp -r skill-overseas-equity-factor-miner ~/.claude/skills/overseas-equity-factor-miner
```

Example trigger prompts:

```text
Mine a few cross-sectional factors on these 30 HK names; screen by 5/10/20-day IC, decay, and turnover; give me the top 5
Generate momentum/value/liquidity candidates on this US universe, run rank-IC validation, and rank them
Run a factor-discovery pass on this HK universe with a point-in-time, peer-median-normalized caliber, and produce a mining report
```

Requires `skill-pandadata-api` installed and available (this skill fetches data through it).

## 🖥️ Output Example

This repo **does not commit generated reports**; results stay local. The report structure is enforced by `scripts/validate_report.py`; the minimal skeleton:

```text
# HK cross-sectional alpha factor mining report
## Summary        (market / universe / rebalance window / horizons / budget / 3-5 findings)
## Candidates     (name · family · formula · inputs · expected sign)
## Compute caliber(point-in-time rule, peer-median normalization, report-caliber dedup)
## Validation     (per-candidate rank IC / IC IR / IC decay / turnover, as a table)
## Ranking        (top-K, with the ranking rule stated)
## Risk & caliber (sample window, lag, survivorship, currency, small-universe caveats)
## Data notes     (which Pandadata method fed which step)
→ Disclaimer: … does not constitute investment advice.
```

Validate a draft report:

```bash
python scripts/validate_report.py your_report.md
# OK → structurally complete; FAIL lists each missing item and exits non-zero
```

## 🔌 Runtime Compatibility

`SKILL.md` is the single entry point; the skill loads in **Claude Code, Codex, Cursor, Hermes, and OpenClaw**, with per-runtime adapters under `agents/` (`cursor-rule.mdc` and `portable-loader.md` are generated by the workspace skill sync).

## 🔗 Data Sources & Dependencies

- **Pandadata HK/US interfaces** (called through `skill-pandadata-api`):
  - HK: `get_hk_daily`, `get_hk_detail`, `get_stock_operating_indicator`, `get_stock_mktfin_indicator`, `get_stock_industry_median`
  - US: `get_us_daily`, `get_us_detail`, `get_stock_operating_metric`, `get_stock_mktfin_metric`, `get_stock_sector_median`
  - Calendar: `get_trade_cal(exchange=HK|US)`
- **Optional public fallback**: Yahoo Finance daily bars, for price/volume only when a Pandadata pull is empty, clearly labeled as a third-party fallback in the report.
- **Depends on**: `skill-pandadata-api` (owns exact method signatures and fields; this skill never calls APIs directly nor invents signatures).

## 📐 Limits & Risk Boundary

| Boundary | Meaning |
|---|---|
| 🔬 In-sample, descriptive | IC / decay / turnover measure historical cross-sectional association, **not future performance**; no cost/borrow/capacity model unless stated |
| 🌐 Single market, single currency | HK and US are never mixed; HKD/USD are never combined or compared |
| ⏱️ Point-in-time | Enforces point-in-time (no look-ahead) and as-of-date universe (no survivorship backfill) |
| 🧮 Peer normalization | Fundamental factors normalized within the peer group via `*_median`; no cross-industry/market percentile |
| 🔢 Small samples | IC is unstable on a tiny universe; the report states the universe size |
| ✋ External writes need an explicit trigger | Saving reports or any publishing requires an explicit user instruction |
| 📛 Not official | Community project, not official/certified/verified; promises no returns |
