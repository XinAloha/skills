# Factor Mason 研究手册

## 这个技能要优化什么
- 让因子定义可审计。
- 把信号质量和执行质量拆开看。
- 把样本清洗当成 alpha 的一部分，而不是前言。

## 默认研究链路
1. 股票池定义
   - 市场、板块、流动性下限、上市年限、ST 过滤。
2. 信号构造
   - 原始特征、滞后规则、标准化、去极值、缺失值处理。
3. 组合逻辑
   - 横截面排序、多空或多头、权重规则、调仓周期。
4. 风险控制
   - 行业、市值、beta、波动率、暴露上限、换手上限。
5. 成本模型
   - 手续费、滑点、买卖价差、融券成本，以及保守的成交假设。

## 关键指标
- IC 和 Rank IC：方向质量
- IR：收益稳定性
- 换手率：维持信号的成本
- 命中率：边际优势是否通过符号检验
- 最大回撤和尾部损失：能否扛住压力
- 衰减曲线：排序后多久还有效

## 隐性失效模式
- 用收盘后才知道的数据，却拿去做收盘到收盘的标签
- 忽略停牌或陈旧价格
- 样本内外使用了同一套股票池过滤
- 只看毛收益高就说因子好，却忽视换手高到失真
- 把行业暴露误认为选股 alpha

## 特色规则
不要急着夸一个因子，至少先过这三个问题：
1. 加上真实滞后后还有效吗？
2. 加上成本模型后还有效吗？
3. 市场状态变化后还有效吗？
