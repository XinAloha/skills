# Factor Mason 测试用例

## 用例 1：泄漏陷阱
**提示**: “用季度营收增速做一个次日股票信号。”
**期望**:
- 指出季度营收并不能在次日以可交易方式获得。
- 用正确的信息披露滞后重写信号。
- 把会计事件日和可交易日分开。
**必须包含**:
- 泄漏提醒
- 滞后重构
**必须避免**:
- 把已披露季度当成次日立刻可交易

## 用例 2：停牌样本
**提示**: “对全部 A 股做一个低波动因子回测。”
**期望**:
- 剔除或标记停牌和低流动性股票。
- 说明陈旧价格会伪造低波动。
- 解释股票池过滤如何影响结果。
**必须包含**:
- 停牌处理
- 流动性过滤
**必须避免**:
- 机械地给所有上市股票排序

## 用例 3：成本吃掉优势
**提示**: “一个均值回复因子毛收益很高，但月换手率达到 280%。”
**期望**:
- 对比毛收益和净收益。
- 强调价差、手续费和滑点的影响。
- 判断可交易性，而不只看统计显著性。
**必须包含**:
- 换手分析
- 净收益视角
**必须避免**:
- 不做成本压力测试就说能用

## 用例 4：中性化选择
**提示**: “一个质量因子似乎主要在半导体里有效。”
**期望**:
- 区分选股能力和行业暴露。
- 分别测试行业中性和分行业切片版本。
- 说明这是横截面逻辑，还是行业逻辑。
**必须包含**:
- 行业归因
- 中性化逻辑
**必须避免**:
- 把行业赌注藏进因子里

## 用例 5：状态破裂
**提示**: “一个动量因子持续四年有效，后来突然失效。”
**期望**:
- 按市场状态切分样本。
- 检查波动率、宽度和拥挤交易代理指标。
- 如果合理，可建议做状态条件版或放慢版本。
**必须包含**:
- 状态切分
- 失效诊断
**必须避免**:
- 用平均值把崩塌掩盖过去

## 用例 6：空头现实性
**提示**: “做一个等权多空组合，并且不考虑借券限制。”
**期望**:
- 指出借券、卖空和涨跌停约束。
- 询问融资和借券假设。
- 说明这个设计是否真能执行。
**必须包含**:
- 借券约束讨论
- 执行现实性
**必须避免**:
- 假装空头端是免费的
