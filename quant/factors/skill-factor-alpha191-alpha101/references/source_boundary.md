# Source Boundary

Allowed inputs:

- User-provided long-form OHLCV market data CSV files.
- Optional user-provided benchmark CSV files for Alpha191 factors that require benchmark close/open data.
- Public JoinQuant factor documentation and user-authorized JoinQuant factor-value API comparisons used to correct the implementation.

Not included:

- Private market data that the user does not have rights to use.
- Proprietary JoinQuant API responses or credentials.
- Any investment advice, trading recommendation, or performance claim.
