# 复盘反模式

| 反模式 | 修复 |
|---|---|
| 只看分数最高的那个因子，不看整体结构 | 强制三层结构（量化 / 结构 / 建议） |
| 给"再加 5 个新因子"这种泛泛建议 | 每个建议必须有 op_type + 具体函数名 + 预期分数 |
| 忽略 CRASHED 的实验 | CRASH 也是研究信号（哪些方向是禁区） |
| 不算相关性矩阵就推荐"加新因子" | 必先做 Layer 2.2，确认不会触发门控 |
| 不看分数轨迹动力学就建议"继续微调" | 平台期必须 phase transition |
| 把 train IC 高就当好 | 永远以 val 段评分为准 |
| 看了 test 段表现 | test 段严格不可见（黑名单禁词） |
| 复盘时间太频繁（每 5 轮做一次） | 至少 30 轮 / 10 因子才有意义 |
| 复盘后不归档 | 每次复盘要写到 journal/notes/review_YYYY-MM-DD.md |
| 假设和 Layer 2 数据脱钩 | 每个假设必须引用 Layer 2 的具体发现 |
| 不给优先级 | 必须排 H1 > H2 > ... 顺序 |
| 不写风险预警 | 强制 ≥ 3 条 |

## 复盘时机

| 信号 | 建议 |
|---|---|
| 接受率 < 15% 持续 10+ 轮 | 该复盘了：方向不对 |
| 提分动力学持平 30+ 轮 | 该复盘了：平台期 |
| 因子数 ≥ 10 | 可以复盘了 |
| 准备阶段验收 / 写研究报告 | 必须复盘 |
| 准备 phase transition | 复盘做出决策依据 |

## 复盘的产物

每次复盘必须落两份产物：

1. **`journal/notes/review_YYYY-MM-DD.md`** — 完整报告
2. **`journal/notes/review_YYYY-MM-DD_charts/`** — 配图（score_trajectory.png / corr_heatmap.png / family_distribution.png）

下一次复盘时对比上次的"风险预警是否兑现"、"假设是否被验证"。

## 不要做的事

- ❌ 把复盘当"整理文档"看 —— 它是"研究方向决策"
- ❌ 不读上次复盘就写新复盘 —— 看不到趋势
- ❌ 同一份复盘交给所有阶段 —— 不同阶段重点不同（早期看探索 / 后期看收敛）
- ❌ 复盘建议被 runner 自动跑 —— 假设是要人脑评估的，不是自动执行
