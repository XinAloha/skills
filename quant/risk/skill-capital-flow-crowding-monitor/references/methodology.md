# 跨市场资金面/拥挤度方法论 (methodology)

## 三源口径

判断一只股票/板块的资金面，需要把三类互不相通、代表不同资金主体的数据统一：

| 源 | 接口 | 代表资金 | 强度取自 |
|---|---|---|---|
| 融资融券 | `get_margin` | 杠杆资金/散户情绪 | `margin_balance`（融资余额）窗口变化率 |
| 北向持股 | `get_hsgt_hold` | 外资/聪明钱 | `holding_ratio`（持股比例）窗口差分 |
| 大宗交易 | `get_block_trade` | 机构/大股东 | 净承接额（机构方向 × 规模）+ 自算折溢价 |

## 标准化（纯标准库）

三源量纲完全不同（亿元、百分点、万元），须标准化到可比的"资金强度分"：

- **z-score**：`z = (x_t − μ) / σ`，其中 μ/σ 为窗口内序列的均值/总体标准差（`statistics.pstdev`）。正=强于历史均值（净流入/加仓），负=弱于（净流出/减仓）。
- **融资融券**：先把余额水平序列转成逐日变化率序列（`pct_change_series`），再取变化率序列的 z-score → 衡量"流入/流出"而非"存量"。
- **北向持股**：持股比例本身是百分比，用逐日差分（百分点变化）序列的 z-score。
- **大宗交易**：无连续时序，用净承接额（机构买+/机构卖−）做对数尺度压缩 `sign × log10(1+|万元|)`，再叠加平均折溢价倾向修正（±5% 折溢价映射到 ±1）。

### 大宗折溢价自算（接口无现成字段）
```
折溢价% = (成交价 price − 当日收盘价 close) / close × 100
```
- `price` 取自 `get_block_trade`，`close` 须额外取 `get_stock_daily`。
- 正=溢价成交（承接意愿强），负=折价成交（甩卖/出货）。
- 买卖营业部含"机构专用"判为机构方向：机构买=承接(+)，机构卖=出货(−)。

## 一致性 / 背离

对三源强度分取方向（sign，阈值 ±0.05 视为中性）：

- **共识分** `consensus_score = 多数方向源数 / 有效源数` ∈ [0,1]。
- **强共识**：所有有效源同向（score≈1 且无反向源）→ 信号最强。
- **背离**：正负方向并存 → 标注少数派是谁与主流相反（如"北向净流出但两融净流入"→ 多为散户接盘外资出货，警惕）。

## 拥挤度分位（手写百分位）

把"当前综合资金强度"放进历史 N 天分布求分位：

```
percentile = (小于current的天数 + 0.5×相等天数) / 总天数 × 100
```
（手写实现，相等折半以逼近连续分位，不引 numpy。）

- **>90% 分位** → 高拥挤预警：资金强度处历史极高位，交易过挤，警惕反转。
- **75~90%** → 偏拥挤。
- **<10%** → 冷门/被抛弃。
- 历史样本 <20 天 → 标注"样本不足"，分位统计意义弱（建议 ≥250 天）。

## 综合信号合成

| 形态 | 信号 |
|---|---|
| 三源共识流入 + 拥挤度可控 | ✅ 最优：资金合力做多且未过热 |
| 三源共识流入 + 拥挤 >90% | ⚠️ 最危险：合力做多却过热，反转风险最高，谨慎追高 |
| 三源共识流出 | 🔻 资金合力撤离 |
| 方向背离 | ↔️ 分歧大，信号弱化，标注背离源 |
| 拥挤 >90%（无论共识） | ⚠️ 高拥挤预警 |

## 局限

- 北向持股披露有滞后/口径调整（沪股通/深股通合并），须按披露日对齐。
- 大宗交易 T+N 披露、折溢价为日频自算，非实时。
- 拥挤度分位需足够历史窗口（≥250 天）才有统计意义。
- 三源强度等权平均是简化处理，实际可按标的流动性/自由流通盘调权重。
- 仅研究/资金面参考，不构成投资建议。
