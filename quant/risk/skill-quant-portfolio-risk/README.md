# Quant Portfolio Risk

本技能用于在明确的投资 mandate、风险预算、组合约束、流动性边界、交易成本、压力情景和治理控制下，把预测或信号转换为可审计的组合决策。

## 适用场景

适用于组合构建、风险预算、风险平价、波动率目标、基准相对优化、因子和行业暴露控制、考虑换手的再平衡、容量分析、交易前检查、限额监控和交易后对账。

信号发现、特征工程、回测和统计验证请使用 `quant-research`。订单调度、成交建模、路由和执行层交易成本分析请使用 `quant-execution-microstructure`。

## 文件结构

- `SKILL.md`：权威工作流、控制项、结果契约和参考资料路由。
- `README.en.md`：英文项目说明。
- `references/`：组合构建、风险模型、治理和监控指南。
- `scripts/`：权重和组合约束验证工具。
- `agents/`：Codex、Cursor、Hermes 和 OpenClaw 适配入口。
- `CLAUDE.md`：Claude Code 适配入口。

## 默认边界

- 从 mandate 和风险预算开始，明确硬约束、软约束、资本、基准、币种和生效时间。
- 严格区分目标权重、可执行订单、成交持仓和会计持仓；缺失或过期风险输入时默认阻断。
- 将换手、价差、冲击、融资、借券、流动性和压力损失纳入决策与归因。
- 默认仅用于分析、模拟和纸面交易；未经明确授权不改变经纪商或账户状态。
- 本项目不构成投资建议，不承诺收益，也不代表 QUANTSKILLS 官方认证或生产批准。
