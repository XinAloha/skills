# Portable runtime loader

For Hermes and other portable runtimes, load `SKILL.md` as the authoritative
instruction file. Resolve referenced paths relative to this repository, read
`references/backtest-guide.md` before the first report, and use
`scripts/run_backtest.py` for reproducible calculations. The skill is
offline-first and outputs research material only; it does not give investment
advice or guarantee returns.
