# 演练剧本

| 场景 | 注入 | 期望结果 |
|---|---|---|
| 成功 | 让全部验收检查通过 | 独立验证后完成并保存证据 |
| 虚假完成 | 执行动作成功、验收检查失败 | 不完成，进入修复或升级 |
| 无进展 | 连续轮次产生同一失败指纹 | 触发停止或外循环重规划 |
| 断路器 | 让同一工具持续失败 | 达重试上限，报告原因与证据 |
| 中断恢复 | 在副作用后、状态更新前停止 | 对账后不重复执行副作用 |
| 重复触发 | 同一事件两次到达 | 去重/幂等键只保留一个有效任务 |
| 闸门 | 请求合并/发布/外部写入 | 无人工批准不得执行 |

演练使用 fixture、临时工作树或测试环境，绝不以生产副作用验证防护栏。
