# 审计清单

- 目标：每个成功主张都有命令、查询或批准证据；独立验证者不复用执行者结论。
- 护栏：迭代、时间、成本、并发、工具重试、无进展和硬停止均有阈值。
- 触发：事件过滤、去重键、并发和无发现收尾明确。
- 隔离：并行写操作使用工作树或等价隔离；共享状态有租约/事务策略。
- 状态：原子更新、检查点、失败指纹、恢复对账和敏感数据规则存在。
- 权限：允许动作最小化；合并、部署、生产写入和外部通知有人工闸门。
- 反馈：每轮快速检查、集成检查、定期漂移扫描和传感器盲区评估存在。
- 观测：动作、证据、成本、状态转换和失败可追踪，运行时日志/指标/追踪可查询。
- 改良：失败与审查意见可进入规则、测试、文档或传感器的受审查改动。
