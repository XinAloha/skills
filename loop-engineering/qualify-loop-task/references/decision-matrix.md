# 决策矩阵

| 条件 | 选择 | 原因 |
|---|---|---|
| 步骤固定，输入输出确定，无需判断 | 确定性自动化 | 不为模型判断支付成本 |
| 有反馈，终态可测，动作可隔离 | 封闭式单循环 | 默认起点 |
| 需要探索但副作用低 | 有预算的开放式探索 | 先获得知识，不自动落地 |
| 独立子任务和验证收益明显 | 多角色/流水线 | 用隔离与汇总换吞吐 |
| 目标主观、规范缺失或不可逆风险高 | 人工主导 | 人承担判断和责任 |
| 缺测试、状态、观测或恢复 | 先补基础设施 | Loop 不能替代护栏 |

反例：持续“优化产品直到更好”没有指标、预算或所有者，不得启动。正例：在隔离工作树中修复指定失败测试，最多 5 轮，不自动合并。
