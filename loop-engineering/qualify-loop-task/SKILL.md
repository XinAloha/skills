# 评估 Loop 任务

1. 收集触发源、目标、可观察证据、允许动作、失败后果、频率、数据敏感性和人工所有者。区分已验证事实与假设。
2. 用 [references/readiness-gates.md](references/readiness-gates.md) 做硬门槛：可验证终态、反馈信号、预算、隔离/幂等、权限边界、恢复和升级。缺任一项时不能批准无人值守。
3. 用 [references/decision-matrix.md](references/decision-matrix.md) 选择人工、自动化、单循环或多角色；默认选择最小且封闭的方案。
4. 产出一个可执行试点：单个触发器、一个工作项、一个工作树/隔离环境、少量检查、硬预算和人工闸门。

## 交付标准

输出判定、证据、未知项、禁区、试点验收和升级人。至少包含一个应触发与一个拒绝触发实例；不得把“模型能生成结果”视为运行资格。
