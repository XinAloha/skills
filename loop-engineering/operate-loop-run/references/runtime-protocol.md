# 运行协议

## 分流

将每个发现写成独立项：`id`、来源事件、证据、范围、风险、去重键、所有者、状态和下一动作。无证据或范围过大的发现进入人工分流，不直接派发。

## 单工作项

1. 获取租约，并在 `agent/<task-id>` 或契约指定的非 `main` 分支工作树中记录执行环境、开始时间和预算快照。
2. 实施者只做契约允许的最小行动；每次写入后运行最快的相关检查。
3. 保存差异、测试/运行时证据、失败指纹与状态转换。
4. 验证者独立复验契约证据；失败时给出可行动反馈，回到实施者或升级。
5. 通过时生成交接包：变更摘要、证据、风险、回滚/恢复、所需批准和草稿 PR 链接。禁止直接推送远端 `main` 或自动合并。

## 平台适配

调度器、工作树、子智能体、MCP、CI 和议题系统均是可替换适配器。每个适配器先做只读能力探测，再记录其命令、权限、错误语义和清理方式；不要因为某个平台“通常支持”就假设当前项目可用。
