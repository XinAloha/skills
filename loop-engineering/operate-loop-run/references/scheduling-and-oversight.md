# 调度、上限与人工入口

定时循环在上线前选择并验证调度器：本地任务适合依赖本机资源的短周期任务；云端/CI 调度适合机器离线仍需运行的任务；会话内重复仅适合有人值守的短循环。记录时区、触发频率、运行环境、凭据范围、无发现时的归档方式和暂停入口。

每个独立运行必须设置三个独立上限：单次墙钟超时、周期/每日成本或令牌预算、单工具最大重试次数。三者中任一触发时停止、保存状态、给人工入口；不要以“下次再试”绕过断路器。

先完成至少三轮受控运行，验证它会按时醒来、不会重复同一事件、报告可读且人工入口有效，再声明为稳定自动化。对会产生 PR 或代码变更的循环，安排每日最少抽样审阅一个产物：人必须能解释变更、原因和证据。无法解释时暂停扩张，而不是提高并发。

不确定事项进入收件箱/分流队列，而不是自动关闭、自动删除、自动发布或自动合并。
