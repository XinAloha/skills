# 反馈生命周期

| 时机 | 运行内容 | 目的 |
|---|---|---|
| 任务开始 | 项目规则、架构、API/测试指南、只读探测 | 降低首次偏差 |
| 每轮编辑后 | 格式、类型、局部测试、策略检查 | 秒级自我修正 |
| 提交/PR 前 | 模块测试、结构测试、独立审阅 | 阻止局部正确、全局错误 |
| 集成后 | 全量测试、性能、安全、端到端验证 | 发现跨模块退化 |
| 定期 | 死代码、依赖、覆盖质量、文档/规则漂移、SLO | 防止慢性退化 |

控制输出格式：`rule_id`、文件/资源位置、观察到的值、预期值、证据链接、建议修复命令、是否可自动修复。若传感器从不触发，也要评估其盲区而不是默认质量很好。
