# 改良闭环

`观察 → 分类 → 根因假设 → 最小控制改动 → 回归验证 → 指标复查 → 版本化沉淀`

| 观察 | 优先改动 |
|---|---|
| 智能体误解稳定规则 | 补项目规则/示例，必要时补结构检查 |
| 同类结构问题重复 | 自定义 lint、测试或代码生成模板 |
| 运行时事实不可见 | 增加隔离环境、日志、指标、追踪或可查询接口 |
| 一直重复相同失败 | 修正失败指纹、反思摘要、断路器或外循环策略 |
| 文档与代码不一致 | 文档校验、所有者、园艺扫描和 PR |
| 成本高但收益低 | 收窄任务、降低频率、改回单循环或确定性自动化 |

单个轶事不能直接形成全局规则；至少确认重复、影响或明确的安全风险之一，并记录反例与撤销条件。
