# 设计 Loop 状态与记忆

1. 读取 [references/memory-model.md](references/memory-model.md)，分离项目语义记忆、任务运行状态、情节日志、共享协调记忆与敏感数据；为每类指定所有者、读者和保留期。
2. 使用 `.loop/state.json` 记录任务进度、预算、检查点、证据、失败指纹和下一动作；用 `journal.md` 追加事实，不用状态文件承载完整历史。
3. 定义上下文组装顺序：项目规则 → 当前契约 → 当前状态 → 最近证据 → 少量相关记忆 → 本轮输入。压缩长历史，禁止无筛选全量注入。
4. 定义写入规则：仅保存可复用的决策、已验证事实、失败教训与恢复信息；记录来源、时间、作用域和失效条件。模型推断必须带置信/待验证标记。
5. 按 [references/storage-and-recovery.md](references/storage-and-recovery.md) 配置原子写、幂等键、并发协调、崩溃恢复、回放和过期清理。

## 成功标准

从任意轮中断后，新进程可在不重放副作用的前提下恢复；它能解释当前事实来自哪里、哪些假设未验证、为何不重复已失败路径。
