# 存储、并发与恢复

| 场景 | 存储 | 控制 |
|---|---|---|
| 单任务、单写者 | JSON + Markdown | 临时文件后原子替换、`schema_version` |
| 本机多任务 | SQLite | 事务、唯一任务键、租约/心跳 |
| 分布式执行 | 数据库/队列 | 幂等键、租约超时、审计和备份 |

恢复步骤：读取契约与最后一致检查点 → 检查租约/运行实例是否仍存活 → 对账外部副作用 → 重新运行只读验证 → 选择恢复、补偿或升级。禁止仅凭进程退出码判定任务未执行。

每次状态迁移保留 `previous_status`、时间、原因、证据链接和操作 ID。使用失败指纹与动作参数判断重复；超过契约阈值后触发断路器或外循环重规划。
