# 记忆模型

| 类别 | 内容 | 典型载体 | 写入规则 |
|---|---|---|---|
| 项目语义记忆 | 架构、规范、决策、接口 | 已版本化 Markdown/规则 | 人工或受审查更新 |
| 任务状态 | 阶段、预算、检查点、下一动作 | `state.json` | 每轮原子更新 |
| 情节记忆 | 行动、观察、失败指纹、结果 | `journal.md`/事件表 | 追加，保留证据链接 |
| 反思记忆 | 可复用失败教训 | 任务摘要或规则候选 | 仅经证据或人工确认后提升 |
| 共享协调记忆 | 任务租约、分配、冲突 | SQLite/队列 | 单写者或事务 |
| 用户/敏感记忆 | 偏好、凭据、业务数据 | 受访问控制的存储 | 最小化、到期、审计 |

检索以当前任务、文件范围、时间和所有者过滤；优先少量高置信、最近、可追溯记忆。过期或与当前证据冲突的记忆降级为待验证，不能静默覆盖项目规则。
