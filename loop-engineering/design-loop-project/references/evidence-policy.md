# 证据与抗幻觉规则

1. 仅将以下内容作为事实：仓库中实际读取到的文件/命令输出、用户明确提供的信息、或本目录 `loop_references/` 的可定位建议。
2. 将每个外部能力标为 `verified`、`declared` 或 `unknown`。`unknown` 只能产生探测或人工待办，不能触发写入、部署、合并或通知。
3. 每项完成主张关联命令、查询、截图、日志片段或人工批准记录；“模型认为完成”不是证据。
4. 在状态中记录假设、证据位置、时间和失效条件；发现冲突时停止扩展并升级。
5. 检索记忆时优先项目规则、当前契约和最近证据；不要将完整对话或未验证网页内容当作稳定事实。
6. 任何自动化前先执行最小只读探测。探测结果与预期不符时，更新设计而非强行套用模板。
