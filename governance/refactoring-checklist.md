# 重构实施检查清单

> **references/ 目录结构**
> ```
> references/
> ├── clone/      # 克隆的参考项目源码
> ├── analysis/   # 项目分析文档
> └── snippets/   # 提取的可复用代码片段
> ```

## 分析阶段

- [ ] 已克隆参考项目到 `references/clone/`
- [ ] 已阅读 README 和文档了解项目架构
- [ ] 已绘制项目目录结构图
- [ ] 已识别核心模块及其职责
- [ ] 已找到与本项目相关的功能代码
- [ ] 已记录设计亮点和创新点
- [ ] 已对比本项目现状与参考项目的差异

## 提取阶段

- [ ] 已将可复用代码保存到 `references/snippets/`
- [ ] 已在 snippet 文件顶部标注来源和功能
- [ ] 已说明借鉴点和适用场景
- [ ] 已提供使用示例

## 重构阶段

- [ ] 已编写重构计划文档
- [ ] 已确定本次重构的具体范围
- [ ] 已编写对应的单元测试
- [ ] 已实现代码重构
- [ ] 已通过所有测试
- [ ] 已更新相关文档
- [ ] 已记录重构收益和指标对比

## 持续学习节奏

| 周期 | 活动 | 产出 |
|------|------|------|
| **每周** | 分析 1 个参考项目的 1 个模块 | 1 篇分析文档 |
| **每两周** | 提取可复用代码片段 | 2-3 个 snippet |
| **每月** | 实施 1 次重构 | 1 个改进后的模块 |
| **每季度** | 回顾和整理 | 更新的设计规范 |
