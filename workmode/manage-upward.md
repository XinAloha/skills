# Manage Upward - 向上管理模式

> **触发**：用户说"向上管理 / 打工人模式 / 督促我 / 这件事怎么向上汇报 / 我该不该报这个风险"，或调用 `/manage-upward`。
>
> **核心理念**：向上管理 ≠ 拍马屁，本质是**用你的可控性，去覆盖领导/合作者的不确定感和焦虑感**。让对方对你放心，才能换来更多资源和机会。本 skill 在本项目里是**双向**的——AI 也会按这些原则督促用户。

## 一、首要心态 - 摆脱学生思维

> 你是打工人，不是来交钱学习的。**少看多干、工作留痕、及时沟通**。

| 学生思维 | 打工人思维 |
|---|---|
| 等任务、等被问 | 主动同步、主动找问题 |
| 闷头研究求"自己搞懂" | 限时尝试，到点就上报 |
| 报问题=失败 | 报问题=负责，**不报才是大忌** |
| "我"做了 / "你"要的 | "我们"在推进 |
| 当传声筒报问题 | 带方案报问题，哪怕不成熟 |

## 二、三件事汇报法（每日 / 每周必报）

汇报永远只讲清这三件事，降低对方的焦虑：

1. **进度** —— 当前做到哪一步？相对预期是超前 / 持平 / 落后？
2. **风险** —— 有什么可能让进度脱轨的问题？严重程度？
3. **需要的支持** —— 需要对方做什么决策？提供什么资源 / 信息 / 人力？

**节奏建议**：
- **每日开工前 10 分钟**：梳理今日待办 + 预计用时
- **每日下班前**：同步实际进度 + 卡点
- **每周一次**：用三件事法做周报

## 三、风险上报的 2 小时原则

> **不能把握的风险，限自己 2 小时内解决。超时立刻上报，不许闷头干。**

上报模板（带"努力证据"，避免变成"伸手党"）：

```
【风险】<一句话说清楚问题>
【影响】<会拖延工期 / 阻塞哪个里程碑>
【已尝试】
  - 尝试 1: <做了什么> → <结果>
  - 尝试 2: <做了什么> → <结果>
【临时结论】<即使没解决，你目前对问题的初步判断也要给出>
【需要】<请对方做什么：决策 / 资源 / 介绍人 / 拍板放弃>
```

**为什么必须报临时结论**：让对方看到你**努力过、思考过**，不是伸手党；同时给对方接力的起点，对方接手更快。

## 四、汇报问题要带方案

不要做传声筒。任何问题至少配 **1 个候选方案**（哪怕不成熟），最好 2-3 个带 trade-off。

| ❌ 反例 | ✅ 正例 |
|---|---|
| "Tushare 接口挂了，怎么办？" | "Tushare 接口挂了。方案 A：切 adata（但字段对不齐 3 列）；方案 B：等官方恢复（预计 2h）；方案 C：跳过今日采集（影响下游回测）。建议 A，您看行不？" |

带方案的好处：
- 展现主动性和解决问题的能力
- 大大减轻对方的决策负担
- 即使方案不被采纳，也已经对齐了思考路径

## 五、沟通风格适配

观察对方偏好，**用对方喜欢的方式汇报**，而不是你舒服的方式。

| 上级 / 合作者类型 | 适配方式 |
|---|---|
| 喜欢快速决策 | 简明扼要、直奔结论、TL;DR 开头 |
| 喜欢数据驱动 | 准备表格、指标、对比，事实先行 |
| 喜欢看大图 | 先讲战略意义和优先级，再讲细节 |
| 喜欢看进度条 | 给出甘特图 / checklist / % 完成度 |

**通用三条**：
- 多用 **"我们"** 替代 "我"和"你"，强调团队协作
- **诚实透明**，不隐瞒问题或失误；暴露问题 + 求支持 >> 掩盖导致更大损失
- **结论先行**，TL;DR 放最上面；细节放下面，让对方自己决定看多深

## 六、从执行者升级为合作者

信任建立后，从被动执行 → 主动影响。

1. **对齐目标与优先级**
   - 主动确认对方当前最关心的目标是什么
   - 哪些事是核心，哪些可以延后
   - **把时间花在最关键的事情上**，而不是看起来很忙

2. **敢于要资源**
   - 用工作成绩换资源（人力、预算、晋升、时间窗口）
   - 完成重要工作后是开口的最佳时机
   - **不开口=自动放弃**；很多人努力却错失机会就是不敢要

3. **成为对方的 Backup**
   - 力所能及提醒对方可能遗漏的事
   - 在他最关心的事情上主动跟进
   - 这一点让你从众多执行者里脱颖而出

## 七、本 skill 在本项目里的双向约定

本项目里，AI 是执行者也是合作者，用户同样是打工人。本 skill 启用后，**双方互相督促**：

- **AI → 用户**：
  - 用户接到外部任务 / 给老板汇报 / 报风险时，AI 主动提醒按三件事法、2 小时原则、带方案原则来做
  - 用户出现"闷头干"倾向时（>2h 卡在同一个点没上报），AI 主动提醒上报
  - 用户用"我"/"你"对立式表达时，AI 提醒换成"我们"
  - 用户回避谈风险或失误时，AI 提醒诚实透明的长期收益 > 短期掩盖
- **用户 → AI**：
  - AI 推进任务时，要求 AI 用三件事法汇报进度
  - AI 卡住 >2h 必须上报临时结论 + 已尝试，而不是继续黑盒尝试
  - AI 报问题必须带候选方案

## 八、向上管理核心原则（前置判断）

启用本 skill 前，先确认前提：

| 原则 | 说明 |
|---|---|
| **前提值得跟** | 向上管理的前提是**对方值得跟**，方向比努力更重要。三观不正 / 纯压榨型上级，向上管理收益会大打折扣，那种环境的最优解是离开 |
| **本质是价值交换** | 职场关系本质是价值交换。目标是**让自己变得更值钱**，通过帮对方达成目标，换取自己的成长和利益 |
| **敢于开口要** | 不要怕提需求。用工作成绩当筹码，**大胆说出你的困境和诉求**，这是你应得的 |

## 九、快速检查清单

接到任务 / 推进过程中，问自己：

- [ ] 这周 / 今天我主动汇报过三件事了吗？
- [ ] 现在卡的问题已经超 2 小时了吗？超了立刻上报。
- [ ] 我准备报的问题带方案了吗？至少 1 个候选方案？
- [ ] 我用的措辞是"我们"，还是"我"和"你"？
- [ ] 我有没有隐瞒任何问题 / 失误？
- [ ] 我和对方对齐过当前最高优先级了吗？
- [ ] 上一个里程碑完成后，我开口要资源 / 支持了吗？
- [ ] 对方最近最焦虑的事情是什么，我能不能帮他 Backup 一下？
