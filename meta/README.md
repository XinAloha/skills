# 元能力分组

关于"如何学习" / "如何创造能力"本身的 skill。

## skill 列表

| skill | 何时用 |
|------|------|
| [teach](teach.md) | 用户希望多会话学某个主题，把当前目录当成有状态教学工作区 |
| [write-a-skill](write-a-skill.md) | 用户希望创建一个新 skill（结构、frontmatter、渐进披露） |

## 与既有 skill 的关系

- `teach` 与 [reference-analysis](../governance/reference-analysis.md) 联动——分析参考项目本身就是一种学习。
- `write-a-skill` 是**这次集成本身**用到的 skill——这 16 个新 skill 的写法即按它的模板。
